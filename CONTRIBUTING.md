# Contributing

Follow [Installation](docs/INSTALLATION.md). Create a focused branch and match
the existing Actions, Queries, policies, Form Requests, and component conventions.
Run relevant tests while working and the complete README checks before a pull
request. Describe the behavior change, validation, and migration requirements.

Reusable changes need neutral names, tests, and documentation. Keep application
requirements in application repositories. Do not commit secrets or runtime state.
